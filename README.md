## 📌 Sobre o Projeto

O **CINEA** é um aplicativo mobile voltado para fãs de cinema e cultura pop.

A plataforma tem como objetivo centralizar diferentes etapas da experiência cinematográfica em um único ambiente, permitindo que o usuário descubra novos filmes, consulte informações sobre títulos, publique avaliações, acompanhe opiniões da comunidade, organize filmes em Tier Lists e encontre os serviços de streaming nos quais cada conteúdo está disponível.

O projeto busca transformar a curadoria pessoal de filmes em uma experiência mais **visual, social, interativa e compartilhável**.

# 🎯 Problema

Atualmente, a experiência de descobrir, avaliar e discutir filmes é fragmentada entre diversas plataformas.

Um usuário pode precisar utilizar:

- uma plataforma para encontrar informações sobre filmes;
- outra para consultar avaliações;
- outra para descobrir onde assistir;
- ferramentas externas para criar rankings;
- editores de imagem para produzir Tier Lists;
- redes sociais para compartilhar suas opiniões.

Essa fragmentação gera uma experiência pouco integrada.

Além disso, grande parte das plataformas existentes trabalha principalmente com listas tradicionais, avaliações textuais e notas numéricas, sem aproveitar totalmente o aspecto visual e social presente na cultura cinematográfica.

---
